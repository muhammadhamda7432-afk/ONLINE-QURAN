Blog & Articles Manager

Use this private dashboard to create and publish Quran-learning articles. Published articles are added to the blog and built as individual pages for search engines.

Open the publishing dashboard →

First-time setup: GitHub sign-in must be connected once by configuring a GitHub OAuth App and adding its Client ID and Client Secret as Vercel environment variables. Follow the setup instructions in the repository.

Publishing steps

  1. Sign in with the GitHub account that has access to the website repository.
  2. Open Blog Posts and choose New Blog Posts.
  3. Add a clear title, URL slug, description, publish date, and the full article.
  4. Click Publish. Vercel will build and deploy the article automatically.
